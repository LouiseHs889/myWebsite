Java Stream

Java Stream

當我開始接觸物聯網（IoT）相關資料後，發現 Java Stream API 中的一些操作在資料處理上非常實用。原本需要透過多層 for 迴圈與暫存變數才能完成的處理流程，透過 Stream 可以用較簡潔的方式表達，也能讓程式的意圖更加清楚。

實務上，IoT 系統經常會從資料庫撈取大量設備、感測器或歷史紀錄，再針對查詢結果進行後續的資料處理。因此，以下的例子會以「從資料庫取得資料後，再使用 Stream 進行處理」作為主要情境。

1. filter　&　map

filter: filter() 的用途是根據條件篩選資料，只保留符合條件的元素。資料庫可以有效處理的篩選條件，優先考慮放在 SQL；取得資料後的 Java 物件處理，則可以使用 Stream 的 filter() 。

map:

它跟 Java 的 Map<K,V>不一樣，剛開始寫的時候我也被這兩個搞混了一段時間。

map() 的核心概念是一對一的資料轉換，也就是：Stream 裡的每一筆資料，要轉換成什麼？

例如，從資料庫撈出的資料通常會包含很多欄位，但後續處理時不一定需要全部欄位。如果需要將資料轉換成 DTO，就可以透過 map() 進行轉換。

除了 DTO 轉換之外，如果只需要每筆資料中的某個欄位，也可以使用 map() 取出來；或者想對某個欄位的值進行統一轉換，例如將數值全部加上某個數值，也可以使用 map() 。

  • Map<k,v>：Java 中的資料結構，用來儲存 Key-Value 關係。
  • Stream 的 map()：用來將 Stream 中的每一個元素轉換成另一個元素。

我怎麼選 Stream function

filter → 我想留下哪些資料？
map → 每筆資料要轉換成什麼？
reduce → 多筆資料最後要合成什麼？
groupingBy→ 我要按照什麼條件分組？
sorted → 我要按照什麼條件排序？
flatMap → 一筆資料拆成多筆後，我想把它們攤平
